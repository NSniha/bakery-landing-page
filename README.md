# Bakery Landing Page

A modern, responsive landing page for a bakery/food business, built with React and Vite. Designed to present a bakery's story, menu, and products through a clean, fast, mobile-friendly interface.

## Features

- Responsive, food-focused landing page design
- Built with React + Vite for a fast dev and build experience
- Clean, modern UI suited for a bakery, cafe, or restaurant brand
- Modular components for easy customization (Hero, About, Menu, Contact)
- Mobile-first, cross-device layout

## Getting Started

### Prerequisites

- Node.js v16 or higher
- npm or yarn

### Installation

```bash
git clone https://github.com/NSniha/bakery-landing-page.git
cd bakery-landing-page
npm install
npm run dev
```

The app runs by default at `http://localhost:5173`.

### Build for Production

```bash
npm run build
```
